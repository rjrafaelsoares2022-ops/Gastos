# FocusMatriz

Controle de pendências pela Matriz Eisenhower, feito para usar no celular.

- **Q1 🔥 Faça agora**: urgente e importante
- **Q2 ⭐ Agende**: importante
- **Q3 ⚡ Delegue**: urgente
- **Q4 🌱 Elimine**: nem urgente nem importante

É um arquivo só (`index.html`). As tarefas ficam salvas no navegador do aparelho.
No menu `⋯` dá para exportar e importar planilhas Excel, nas mesmas colunas do app antigo.
